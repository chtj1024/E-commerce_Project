# Performance Tests

프로젝트의 성능 테스트와 개선 실험을 목적별로 관리합니다.

## 실험 목록

- `redis-cache`: 상품 단건 조회의 기본, Redis Cold/Warm Cache 성능 비교
- `index-tuning`: 상품 검색 SQL의 인덱스 적용 전후 실행계획 및 API 성능 비교

각 실험의 실행 방법과 결과 해석은 해당 디렉터리의 `README.md`에 기록합니다.

## 공통 측정 원칙

- Before와 After는 같은 데이터와 요청 조건으로 측정합니다.
- 평균뿐 아니라 p95, p99, 처리량, 실패율을 함께 기록합니다.
- 여러 차례 반복 실행하고 실측한 결과만 문서에 사용합니다.
- 원본 결과는 각 실험의 측정 도구별 `results` 디렉터리에 보관합니다.
